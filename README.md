# Rock Paper Scissors Game

## Project Overview
This project is a simple yet interactive implementation of the classic Rock Paper Scissors game. It is part of **The Odin Project** curriculum and focuses on building fundamental skills in HTML, CSS, and JavaScript. The game allows users to play against the computer, with live score updates, round-by-round results, and a final game outcome display.

## Features
- **Interactive Gameplay**: Play Rock, Paper, Scissors against the computer.
- **Live Scoreboard**: Displays the current scores for both the human player and the computer.
- **Round History**: Logs the results of each round in a scrollable section.
- **Game Outcome**: Declares the winner when either the human or computer reaches 5 points.
- **Responsive Design**: Styled using CSS for a clean and user-friendly interface.
- **Dynamic DOM Updates**: Robust JavaScript logic ensures smooth updates to the UI.

## How to Play
1. Open the `index.html` file in your browser or visit the live version of the game at [Rock Paper Scissors](https://frenzywho.github.io/rock-paper-scissors/).
2. Click on one of the three buttons (Rock, Paper, Scissors) to make your choice.
3. The computer will randomly select its choice.
4. The result of the round will be displayed, and scores will be updated.
5. The game ends when either the human or computer reaches 5 points. The final result will be displayed.
6. Start a new game by clicking any button again.

## Technologies Used
- **HTML**: Structure of the game.
- **CSS**: Styling for layout, buttons, and scoreboard.
- **JavaScript**: Game logic, event handling, and DOM manipulation.
